Descrizione dettagliata

Gestisce il ServerSocket e accetta le connessioni in ingresso dai client.

Ogni connessione accettata viene affidata a un GestoreClient dedicato.

Il loop di accettazione gira in un thread daemon separato per non bloccare il JavaFX Application Thread.

◆ stop()

void indovinaparola.server.model.ReteServer.stop ( )

Ferma il server chiudendo il ServerSocket.

La chiusura del socket causa un'eccezione nel thread di accettazione, che viene ignorata grazie al controllo su running.

Precondizione
Il server deve essere attualmente in esecuzione.
Postcondizione
Il ServerSocket viene chiuso e non vengono accettate nuove connessioni.
