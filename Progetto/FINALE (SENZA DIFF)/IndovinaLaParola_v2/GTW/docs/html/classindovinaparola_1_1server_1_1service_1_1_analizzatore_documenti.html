Descrizione dettagliata

Analizzatore di documenti testuali.

Calcola la Term Frequency (TF) di ogni parola presente nei file analizzati, usando esclusivamente la Java Stream API.

Implementa Serializable per permettere il salvataggio e il ricaricamento dei risultati dell'analisi senza dover rielaborare i documenti.

La mappa TF viene esposta tramite Collections#unmodifiableMap come oggetto immutabile — tecnica raccomandata dal Modulo 6 (Concurrency) per condivisione sicura tra thread.

String indovinaparola.server.service.AnalizzatoreDocumenti.selectWordFromExcerpt ( String excerpt,
int difficulty )

Seleziona una parola dall'estratto in base al livello di difficoltà.

Con difficoltà alta vengono preferite parole con TF bassa (più rare), con difficoltà bassa parole con TF alta (più comuni e facili).

Usa la Stream API con Comparator lambda (Moduli 4 e 5).

Parametri
[in]excerptestratto da cui selezionare la parola
[in]difficultylivello: 1=facile (parole comuni), 2=medio, 3=difficile (parole rare)
Restituisce
parola selezionata, oppure null se nessuna parola idonea trovata
