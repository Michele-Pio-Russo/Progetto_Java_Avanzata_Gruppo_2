Descrizione dettagliata

Controller JavaFX per il pannello di amministrazione del server.

Questa classe implementa Initializable e funge da controller per l'interfaccia JavaFX del server. Contiene i metodi di gestione degli eventi (handler) associati ai vari componenti dell'interfaccia, come i pulsanti per l'avvio del server e l'analisi dei file.
