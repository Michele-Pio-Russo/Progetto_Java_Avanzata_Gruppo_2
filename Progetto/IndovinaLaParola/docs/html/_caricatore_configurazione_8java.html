Descrizione dettagliata

Gestisce il caricamento dei parametri di configurazione dal file properties del server.

Questa classe permette di istanziare un oggetto CaricatoreConfigurazione. I metodi della classe, in particolare i metodi getter, permettono di estrapolare e leggere i valori delle proprietà definite nel file di configurazione del server.
